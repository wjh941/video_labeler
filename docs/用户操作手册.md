# 视频片段标注工具 · 用户操作手册

> 版本：随代码库更新 · 面向：标注员 / 审核员

## 一、启动与界面布局

启动方式：双击应用或命令行运行 `python app.py`。

```text
┌──────────────────────────────────────────────┐
│ 项目设置卡（可收起：打开工程/导入视频/导出等）    │
├──────────────────────┬───────────────────────┤
│ 视频预览（等比自适应） │ 片段标注区              │
│ 播放进度条（含时间刻度）│  · 行为标签（3列网格弹层）│
│ 操作日志              │  · 场景属性 / 人员身份等 │
├──────────────────────┴───────────────────────┤
│ 片段任务表格（默认收起，点标题展开或"片段列表"弹出）│
├──────────────────────────────────────────────┤
│ 状态行：取消导出 · 片段列表 · 自动保存 · 进度与提示 │
└──────────────────────────────────────────────┘
```

启动时如弹出「恢复上次会话」，选择"是"可直接回到上次的工程、视频和播放位置。

## 二、快速上手：标注一个片段

1. **导入视频**：项目设置卡 →「导入视频」（支持长视频，画面按比例自适应）。
2. **设起点**：播放到片段开始处，按 `S` 或点「设置起始点」。
3. **播放到结束**：按 `空格` 播放；用 `A`/`D` 逐帧微调。
4. **设终点**：按 `E` 或点「设置结束点」。
5. **填标签**：行为标签（可多选）、正负性、光照等。
6. **完成片段**：按 `回车` 或点「✓ 完成片段」。起止点自动顺延为下一段起点。

**连续标注同类片段的最快路径：`S → 空格 → E → R → 回车`**（R 沿用上一条的标签）。

## 三、快捷键总表

### 播放控制

| 按键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `A` / `D` | 上一帧 / 下一帧 |
| `PgUp` / `PgDown` | 后退 / 前进 1 分钟 |
| `Shift+PgUp` / `Shift+PgDown` | 后退 / 前进 10 分钟 |

### 片段编辑

| 按键 | 功能 |
|---|---|
| `S` / `E` | 设起始点 / 设结束点 |
| `回车` | 完成片段（添加或更新） |
| `Ctrl+Enter` | 同上（完成片段） |
| `R` | 沿用上一片段的标签设置 |
| `Del` | 删除选中的片段 |
| `Esc` | 清空当前编辑器 |

### 工程与数据

| 按键 | 功能 |
|---|---|
| `Ctrl+S` | 保存工程 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做片段修改 |
| `Ctrl+Shift+E` | 快速导出 |
| `Ctrl+A` | 任务表格内全选 |

快捷键均可在「配置快捷键」对话框中修改；点「快捷键说明」查看当前生效的绑定。

## 四、效率技巧

- **沿用上一条（R）**：复制上一片段的行为、极性、光照、人群等标签，不复制时间和备注。
- **最近使用置顶**：常用行为标签自动排在弹层最前面。
- **行为标签 3 列网格弹层**：所有选项一屏可见，点选即勾选。
- **时间码跳转**：进度条右侧输入框支持 `1:23.456`、`0:01:23`、`83.5` 三种格式。
- **时间轴悬停**：鼠标停在进度条上即显示该位置的时间；上方有绝对时间刻度。
- **片段列表按钮**：底部状态行一键展开/收起任务表格；表格分离后点它可直接唤出窗口。
- **表格筛选**：支持按行为、正负性、导出状态、审核状态和关键词过滤；表头可排序。

## 五、审核流程

1. 底部点「审核模式：关」切换为开启。
2. 数字键快捷置审核状态：`1` 通过 / `2` 需修正 / `3` 剔除 / `4` 待审核。
3. 「批量修改选中片段」可对勾选的多条片段批量改标签（Shift/Ctrl 点击可多选）。
4. 导出 CSV 前会检查未设置行为标签等异常并给出提示。

## 六、工程、备份与恢复

| 机制 | 说明 |
|---|---|
| 手动保存 | `Ctrl+S`，工程文件为 `.labelproj` |
| 自动备份 | 默认开启；每 30 秒写入工程同目录 `.backups/`，保留最近 10 份 |
| 自动保存（可选） | 底部「自动保存 关/开」开关；开启后每 30 秒自动保存主工程文件（需先保存过一次） |
| 版本快照 | 手动创建 `.versions/` 快照，可随时恢复 |
| 会话恢复 | 记录工程、视频、播放位置；下次启动可一键恢复 |
| 备份恢复 | 「从备份恢复」选择 `.backups/` 内的任意存档 |

> 建议长会话标注时开启「自动保存」；它不会弹出任何对话框，也不会在无工程文件时生效。

## 七、日志与故障排查

- 界面日志：左侧「操作日志」面板，可复制/清空。
- **文件日志**：`%APPDATA%\VideoSegmentLabeler\logs\app.log`（1MB×5 滚动），记录所有状态动作与启动/退出。
- **崩溃报告**：程序遇到未处理错误会弹窗提示，并把完整堆栈写入日志文件；反馈问题时请附上该文件。
- 常见提示：
  - 「无法加载视频」：确认文件存在且编解码器受支持（HEVC/H.264 已验证）。
  - 「读取视频元数据失败」：检查 ffmpeg/ffprobe 路径设置。
  - 「导出文件名重复」：同一输出文件名已存在，调整序号后重试。

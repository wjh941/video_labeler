# 中文界面文案设计

## 目标

将桌面应用的用户可见界面文案改为中文，便于标注工作流使用；保留标签编码、CSV 数据格式和视频输出文件名的英文规范。

## 范围

修改 `video_labeler/ui/main_window.py` 中的：

- 窗口标题、按钮、分区标题、表格列标题和字段标签。
- 文件选择框标题、文件类型说明、占位提示、工具提示。
- 空状态、操作状态和错误弹窗的标题与说明。

保留以下内容不变：

- 行为标签：例如 `strangers_climbs`、`dog_out`、`pool`。
- 正负例、光照和视角值：例如 `pos`、`night_full_color`、`panorama`。
- CSV 列名 `source,start,end,output`、FFmpeg 参数和所有业务数据。
- 文件名格式：`日期-摄像头_视角-行为-正负例-光照-编号.mp4`。

## 文案规则

- 使用简洁的中文动词：`导入视频`、`导入 CSV`、`保存标注 CSV`、`选择输出文件夹`、`批量导出`。
- 保留技术名词 `FFmpeg`、`CSV` 和 `MP4`。
- 成功、失败和进行中的状态均用中文表达，但动态视频文件名、目录和 FFmpeg 错误文本保持原样。
- 保留英文标签的可见文本和实际值，确保标注选择与导出命名一致。

## 验收

- 主窗口中不再出现面向用户的英文操作文案。
- 英文标签和输出文件名生成结果不发生变化。
- 现有 `pytest` 测试继续通过。

## 自检

- 没有未定义项或占位符。
- 范围限定在界面文案，不改变业务逻辑、数据模型或导出协议。
- “全部中文”明确排除了用户要求保留的英文标签和技术/数据格式字段。
